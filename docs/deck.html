Beyond the brief

Real hardware. Real push.
Not simulated.

Web Push · Service Worker · VAPID
It reaches your lock screen
Fires with the tab closed — not an in-app toast. Four categories, on by default, each one switchable off.
Web Bluetooth · GATT Heart Rate
It reads your actual heart rate
The same standard profile chest straps broadcast. Live BPM replaces self-reported activity in the dose math.

Native browser standards. No vendor SDK, no app store, nothing proprietary.

07
Under the hood

Deterministic health logic. One deploy.

01 · Live reading
Google Air Quality returns India's own CPCB index
02 · Classification
Six EPA-style bands across 0–500, each with its own guidance
03 · Personal overlay
Health profile shifts mask, exercise and window advice
04 · Exposure math
Cigarette equivalence and inhaled dose, by breathing rate and age
Health guidance is not AI. An auditable rules engine that can never hallucinate a mask recommendation.
The chat assistant is. Llama 3.3 70B on Groq, grounded on server-fetched live AQI.
One Next.js deploy. ~20 API routes, userId resolved server-side, MongoDB 2dsphere + 24h TTL.
